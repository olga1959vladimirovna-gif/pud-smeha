# Библиотека персонажей

Единый реестр всех иллюстраций, персонажей и их вариаций, используемых в проекте «Пуд Смеха».

Источник: лист-каталог «Набор иллюстраций для проекта "Пуд Смеха"» (техническое задание для будущей генерации/отрисовки).

Статус **«Ожидает генерации»** означает, что PNG-файл ещё не создан и не загружен — только запланирован. Как только файл будет готов, его нужно положить в указанную папку `assets/mascots/...` и обновить статус.
